# Calculator

A browser-based calculator built as part of [The Odin Project](https://www.theodinproject.com/). It supports basic arithmetic with mouse and keyboard input.

## Getting started

Clone the repository and open `index.html` in a modern browser. No build step is required. Bootstrap is loaded from a CDN, so an internet connection is needed for its styling.

```sh
git clone https://github.com/edmond-bobiles/calculator.git
cd calculator
```

## Usage

- Enter numbers and choose `+`, `-`, `*`, or `/`, then press `=` to calculate. The full expression stays visible, and chained operations are evaluated from left to right.
- Use the decimal point, backspace, and Clear buttons to edit input.
- On the keyboard, use the number and operator keys, Enter for equals, Backspace to delete, and Escape to clear.

## Built with

HTML, CSS, JavaScript, and Bootstrap 5.
